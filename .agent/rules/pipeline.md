# Pipeline Rules (Always On)

- Follow the stages in `PIPELINE.md`.
- Before any task, read `PROGRESS.md` to find the current stage.
- Work on **ONE stage at a time**. Never start the next stage until the user approves the gate.
- Do not write application code before Stage 5.
- Every coding task needs a verification command. Run it and fix failures before reporting done.
- After finishing a stage, update `PROGRESS.md` (stage, decisions, open questions).
- Commit only after the user approves.
- One task per prompt. Do not touch unrelated files.
- If the user reports a repeated mistake, add a rule for it to this file.
